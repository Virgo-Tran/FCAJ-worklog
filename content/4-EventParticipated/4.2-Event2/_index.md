### Event Objectives

* Continue the regular technical meetup series under the **First Cloud AI Journey (FCAJ)** program at AWS Vietnam.

* Network, exchange troubleshooting experience, and receive actionable feedback from mentors and senior cloud engineers.

### Speakers & Topics

1. **AWS Study Group Mentors** — *Advanced EKS Operations & Cost Right-Sizing in Practice*
2. **FCAJ Technical Leads** — *Building Production-Ready Event-Driven Pipelines with AWS Lambda & SQS*
3. **Cloud Security Specialists** — *Identity & Access Governance: Least Privilege with AWS IAM & KMS Encryption*

---

### Key Highlights

#### 1. EKS Cost Optimization & Production Container Operations
* Deep dive into Pod resource right-sizing using CloudWatch Container Insights and dynamic node provisioning using Karpenter.
* Explored strategies combining Spot Instances, Graviton ARM CPUs, and VPC Endpoints (eliminating NAT Gateway fees) to reduce infrastructure bills by 40-60%.
* Analyzed compute purchasing models (Savings Plans vs Reserved Instances) tailored for growing engineering teams.

#### 2. Building Production-Grade Serverless Event-Driven Pipelines
* Hands-on workshop on event-driven architecture pairing S3 Presigned URLs, SQS queues, Lambda, and AI services (Amazon Textract).
* Implemented resilient error handling with Dead Letter Queues (DLQs), automated CloudWatch Alarms, and distributed tracing via AWS X-Ray.
* Explored next-generation serverless workflow features for state management.

#### 3. Identity & Data Protection on Cloud (IAM & KMS)
* Applied least-privilege access principles to construct tight IAM policies for microservices.
* Enforced Encryption at Rest and Encryption in Transit using AWS KMS key management.
* Automated threat detection and compliance auditing with GuardDuty, Security Hub, and AWS Macie.

---

### Key Takeaways

* **FinOps Mindset:** Recognized that well-architected cloud systems must incorporate cost optimization and resource right-sizing from day one.
* **Resilient Architecture Skills:** Understood the necessity of robust error-handling layers (DLQ, Alarms, Retry logic) in production services.
* **Security Awareness:** Mastered strict IAM policy construction and KMS encryption to safeguard cloud assets.
